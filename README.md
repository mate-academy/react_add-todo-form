# React Add TODO Form

Projeto desenvolvido em React com foco em criação de formulários, validação de dados e manipulação de estado.

[DEMO LINK](https://Igor-hrm.github.io/react_add-todo-form/)

---

## Sobre o projeto

Este projeto foi desenvolvido durante meus estudos em React.
O objetivo foi implementar um formulário para adicionar novas tarefas (TODOs) a uma lista existente, incluindo validações e atualização dinâmica da interface.

Cada tarefa adicionada passa a fazer parte da lista imediatamente após a validação dos dados.

---

## Tecnologias utilizadas

- React
- TypeScript
- CSS
- Vite

---

## O que foi desenvolvido

- Criação de formulário controlado para adicionar TODOs
- Campo de texto para o título da tarefa
- Select para escolha do usuário responsável
- Validação de campos obrigatórios
- Exibição de mensagens de erro apenas após tentativa de envio
- Remoção imediata do erro ao alterar o campo inválido
- Geração dinâmica do `id` do TODO
- Atualização da lista de tarefas via estado
- Limpeza do formulário após envio válido
- Manutenção da estrutura exigida para testes automatizados
- Deploy da aplicação com GitHub Pages

---

## Aprendizados

Com este projeto, pratiquei:

- Criação de formulários controlados no React
- Validação de dados no front-end
- Manipulação de estado com Hooks
- Atualização dinâmica de listas
- Organização de lógica de UI baseada em estado
